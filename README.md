## FAQ

### Is OmniPatch safe to use? Will it install tool or components?

OmniPatch is designed to modify application files locally on your system. While the tool itself is scanned for tool, any modification of software files carries inherent risk. It is provided 'as-is' and users should run it in a secure environment.

### Which specific versions of the AI applications are supported?

OmniPatch is updated periodically to target the latest stable desktop versions of ChatGPT, Claude, Microsoft Copilot (Windows), GitHub Copilot, Cursor, JetBrains AI Assistant, and Devin. Check the repository's description for the most current compatibility list.

### How does OmniPatch work without an internet connection?

The patcher modifies local installation files or configuration settings within the installed AI applications on your Windows machine. The activation process is performed entirely offline after the initial download.

### How often is OmniPatch updated to support new application versions?

The development team aims to release compatibility updates within 2-4 weeks after a major supported application update is released. Updates will be posted in the GitHub Releases section.

### Will this tool interfere with my existing account or data in these AI apps?

OmniPatch modifies the local application client, not your online account data. It does not interact with or store your login credentials. Your conversation history and account settings remain intact.

### Can this be detected by the AI application providers?

Since OmniPatch alters local files, there is always a theoretical possibility of detection by the application's integrity checks. The method used is designed to be stable, but detection risk cannot be completely eliminated.

### Is there a version for macOS or Linux?

Currently, OmniPatch is developed exclusively as a Windows desktop application (omnipatch.exe). There are no official versions for other operating systems.
